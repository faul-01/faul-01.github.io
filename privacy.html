Privacy Policy

Last updated: 2 November 2026

MM Uploader is a private tool that uploads and schedules videos to the owner's own YouTube channel. This policy explains what Google user data it accesses and how that data is handled.

Data accessed

  • YouTube upload permission (youtube.upload): to upload the owner's videos and set their metadata and publish time.
  • Read-only YouTube account data (youtube.readonly): channel name, ID and public statistics, used to confirm the correct channel is connected.

How data is used and stored

  • Data is used only to upload and schedule videos to the owner's own channel.
  • The OAuth refresh token is stored only on the owner's own computer and server, and is never published or shared.
  • No Google user data is sold, shared with third parties, or used for advertising.
  • This website uses no cookies, analytics or trackers.

MM Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

MM Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Retention and revoking access

Tokens are kept until access is revoked. Access can be revoked at any time from the Google security settings page; after that, the stored token stops working and is deleted.
